# Interiorismo (app para el móvil)

App de interiorismo de uso personal: planos, vista 3D, catálogo, inspiración, materiales y presupuestos.
Funciona sin servidor: los datos se guardan en el propio móvil y se pasan con copias de seguridad.

- Texturas y cielos: [Poly Haven](https://polyhaven.com), CC0.
- Librerías: Three.js (MIT), model-viewer (Apache 2.0), qrcode-generator (MIT). Licencias en `vendor`.
